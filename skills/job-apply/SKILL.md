1. Find jobs: the link the user gave; their recommended jobs (a signed-in job board shows them on its HOME page under "Matches your preferences", "Jobs for you" or "Recommended" — extract_text there; "My jobs" is saved/applied jobs, not recommendations); or the board's search (title + place). A job card's details show beside the list; extract_text: title, company, location, pay, must-haves.
★ SAVED (filled bookmark badge) = a job the user kept: valid pick; never unsave.
2. View/find only → report title, company, location, pay, link and stop. Never click Apply then.
3. Résumé: list_files in the folder the user allowed, read_file the candidates, pick the closest and say why. No folder → upload; the user picks.
4. Click "Apply" / "Apply now" / "Easy apply"; "Apply on company site" → follow it. Sign-in or create-account page → stop and ask the user to sign in.
5. Fill only with facts from the résumé or the request. Unknown answers (salary, visa, start date, references, essays) → ask the user; never invent. Voluntary self-identification → "Decline to answer" unless told otherwise.
6. Continue / Next through the steps; check the review page.
7. Final submit: Bah asks the user. Cancelled → stop and report what is filled.
8. Report job, company, link, confirmation. Apply to no more jobs than asked.
